# 场景覆盖矩阵

实＝已覆盖，指该阶段正向路径在既有设计及适用域中已定义；阻＝需要但被阻塞，待建技能、所需模式或证据未就绪；—＝不涉及。A04 的仿真轨迹不计作实机步态覆盖。拒绝、隔离与补证由具体故障向量单独检验，不能替代受阻的物理效果。表格不代表完成硬件实验。按作用域阅读：一项有已覆盖分支又有受阻分支时，动素列取已覆盖，具体限制以阶段授权为准。感知列评价所需证据在当前档案的可用路径，不能把模拟真值外推到设备。
