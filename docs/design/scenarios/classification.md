# 逐轨归类与边界

1. 先判 S2 与非驱动行为。推理记 PN，选择实例记 ST，主动搜索记 SH，定位瞬间记 FD@t。对照标准 Q 记 I。手保持载荷记 H，即使父链在动。受外部屏障阻塞记 UD，有可执行分支却空闲才记 AD，进入批准的主动恢复模式才记 R。
2. 再判基座。仅 L 轨的基座位移用 x.locomote（Simo 标签 LO）；上身按各轨目的另判。
3. 上肢空手移动用 TE，建立控制用 G，确认支撑后让出用 RL。接合用 A，分开已接合或缠住的部件用 DA。工具、容器或机构产生功能效果用 U；单纯载物位移用 TL，当前用途对位用 P，为之后使用或交接而预置用 PP。
4. 可变形物的 P/PP 依据可观测地标、轮廓与容差策略。缺标准或不可见时把该谓词判 UNKNOWN。
5. 递物给人按给予侧 TL → PP → UD → RL；确认对方独立承接后才允许 RL。对方的 G 可与 RL 重叠。
6. D7 只在留出数据同时证明以下三点时重开：现有码、能力、条件和掩码无法区分重要动作分布；新边界可一致标注；能力级特化仍不能解决。当前语料给出边界反例，尚无这种留出证据。维持原词表。

## 各场景最容易误标的边界

| 场景 | 判别依据 |
| --- | --- |
| A01 | 取得控制的 G 以 acquired 点结束；RH 在 RA 的 TL 区间保持 H，不参加手指动作损失 |
| A02 | ST 由 S2 重绑实体，抬起未知载荷放回是 TL/PP/RL，不是继续旧 G |
| A03 | U 描述开启机构；右臂等待 B1 为 UD，但持物手仍为 H |
| A04 | LO 只标基座位移；停止后 L 的平衡不再标 LO，上身 G/TL 单独分轨 |
| A05 | 倾壶使液体转移标 U；倾倒前对准杯口才是 P。减轻的轴向载荷不能独立证明液体进入目标杯 |
| A06 | G 结束于取得控制；I 依据材料标准看裂纹、压痕或破碎，不能从 G 的终态代推 |
| A07 | 呈递是 PP，等待承接是 UD；给予侧 RL 可与对方 G 重叠，对方手不是本体训练动作轨 |
| A08 | 携带布角移位是 TL，按当前折边地标和标准 Q 对位是 P，手的保持记 H；为后续收纳摆放才是 PP |
| B09 | P 到轴线对准即止；开始配合后是 A，未推进不能反复加力 |
| B10 | 手内调整到当前刀头姿态是 P；对紧固件施加工具功能是 U |
| B11 | 在目录中将预定工具功能归 U；现阶段只验证拒绝路径 |
| B12 | 开门以机构功能记 U；通过是 LO，维持门位需独立保持轨 |
| B13 | 上楼的 L 是 LO；双手 H 和整体搬运的 TL 分轨 |
| B14 | 车轮受推属于 U；腿的位移是 LO，不把推车标为手持载荷 TL |
| B15 | SH 搜索候选；I 对照文字标准；ST 才绑定实例 |
| B16 | 缺深度属于证据状态；主动换视角用 SH/I，不把无回波标为 FD |
| B17 | 空手追踪为 TE，获得控制边界才转 G；目标移动不是 LO |
| B18 | 重复的搬运是多个 TL/RL 实例；核对遗漏是 I，等待通路是 UD |
| B19 | 外部推扰是 MON 事件；停后受阻才记 UD，恢复休息 R 需另有恢复模式 |
| B20 | 松开实际缠结可标 DA；沿路径预置是 PP；端点接合为 A |
